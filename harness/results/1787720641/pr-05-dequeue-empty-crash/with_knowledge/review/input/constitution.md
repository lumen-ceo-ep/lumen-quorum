# Constitution — demo-project

Synthetic knowledge base used only to validate the engine (M0). Not a real codebase's
real rules — invented specifically so this repo never needs real project content to
prove the concept works.

## Rubric

- A finding must cite either a concrete code reference or a rule reference below. A
  claim with neither is not a finding.
- Severity: `blocking` (breaks a stated invariant or causes incorrect behavior on a
  realistic input), `major` (real but recoverable defect), `minor`, `nit`.
- Do not restate what the diff obviously does. State what could go wrong, concretely.
